Pureprompt 사내 협업툴

회사의 네 서비스(온다정·띠링·에이전트원·이음) 팀과 마케터, 개발자가 한곳에서 대화하고 현황과 할 일을 맞춰 가는 사내 협업툴입니다. 슬랙의 구조에 노션·리니어의 장점을 더해, 설계부터 배포까지 맡아 처음부터 만들었습니다.

  • 346개자동 테스트 · API 283 · 화면 63
  • 13곳한국어 검색 함수 하나로 통일
  • 10 × 31화면 폭 × 화면 레이아웃 자동 점검
  • 역할설계 · 개발 · 배포
  • 상태사내 운영 중
  • 기술FastAPI · WebSocket · SQLite · Web Push · Google OAuth
  • 기간2026.09 — 현재

주요 기능

  • 메신저 — 채널·스레드·DM·리액션·멘션·고정 메시지·북마크·예약 전송·나중에 알림. 실시간은 WebSocket
  • 현황 문서 — 채널마다 노션식 문서 한 장, 버전 기록 100개와 되돌리기, 오래 업데이트되지 않은 항목은 월요일에 알림
  • 할 일 — 리니어식 짧은 번호(개발-42)를 대화에 쓰면 카드로 표시, 보드와 하위 체크리스트
  • 일정 — 회사 구글 계정으로 로그인, 각자 허용한 캘린더로 회의 잡기·Meet 링크·10분 전 알림
  • 에이전트 API — 사람이 발급한 키로 AI 에이전트가 진행 상황을 읽고 씁니다. DB에는 키의 해시만 저장

핵심 기여

1. 한국어 사용자를 위한 검색과 입력

문제
사람을 찾을 때 한글 전환을 잊고 skagusdn으로 입력하거나, 초성만 ㄴㅎㅇ으로 입력하는 경우가 많습니다. 한글 조합 중 Enter는 브라우저마다 동작이 달라, 메시지가 두 번 가거나 마지막 글자가 빠질 수 있습니다.
해결
낱말 단위 초성 검색과 두벌식 한영 변환을 하나의 함수로 만들어 사이드바·멘션·검색 등 13곳에 공통으로 적용했습니다. 조합 중 Enter는 브라우저 자동화로 실제 한글 입력을 재현해 검증했습니다.
판단
검색 규칙은 화면마다 따로 만들지 않고 한 함수로 모았습니다. 어디서 찾든 같은 결과가 나와야 하니까요.
결과
ㄴㅎㅇ도 skagusdn도 → 남현우. 첫 화면 데모에서 써 보기 → · 자세한 글 →

2. 디자인을 감이 아니라 기준으로

문제
기능이 빠르게 늘면서 글자 크기 20가지, 높이 13가지, 여백 25가지 값이 화면마다 섞이기 시작했습니다.
해결
값을 :root 디자인 토큰 단계로 묶고, 화면 폭 10가지 × 화면 31개를 자동으로 열어 글자 대비 4.5:1, 터치 영역, 정렬 어긋남을 확인하는 점검 도구를 만들었습니다. 실제 슬랙 화면과 나란히 놓고 치수를 맞췄습니다.
결과
점검 위반 0건 · 자동 테스트 API 283 · 화면 63 (운영과 분리된 테스트 서버에서 실행).

3. 현황이 실제와 어긋나지 않게

문제
일은 대화에서 끝나는데 현황표는 누군가 고쳐야 바뀝니다. 그대로 두면 표는 며칠 전 상태에 머뭅니다.
해결
작업을 마칠 때마다 '무엇이 바뀌었는지'를 한 묶음으로 기록해 서버에 반영하는 경로를 만들었습니다. 같은 묶음을 두 번 반영해도 결과가 같고(멱등), 사람이 직접 고친 항목은 덮어쓰지 않습니다.
결과
네 서비스 채널의 현황과 할 일이 그날의 작업 기록과 맞춰집니다.

회고

  • 다른 제품을 참고할 때는 '느낌'이 아니라 치수를 재서 맞춥니다.
  • 비밀값은 응답·실시간 메시지·로그 어디에도 싣지 않고, 꺼내는 경로를 하나로 둡니다.
