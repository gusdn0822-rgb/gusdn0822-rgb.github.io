온다정 담당자 앱 — 현장에서 일하는 담당자를 위해

노인 일자리 기관의 담당자는 사무실보다 현장에 있을 때가 많습니다. 오늘 누가 출근했는지, 다시 걸어야 할 전화가 있는지, 어르신 한 분의 이번 주 근무가 어떤지를 휴대폰에서 바로 확인할 수 있게 만든 앱입니다. 웹 서비스와 같은 서버를 씁니다.

  • 역할설계·개발 (Flutter)
  • 상태시제품 — 안드로이드 우선
  • 기술Flutter · Provider · 카카오 로그인
  • 기간2026.10 — 현재

화면

앱의 체험 모드 화면입니다. 이름과 기관은 모두 예시 데이터입니다.

주요 작업

1. 크기와 색을 한 곳에서 관리

작업
간격·모서리·버튼 높이·글자 크기를 tokens.dart 한 파일에 모으고, 웹 서비스의 디자인 토큰과 값을 맞췄습니다. 화면 코드에는 숫자를 직접 쓰지 않습니다. 어르신을 돕는 담당자용 앱이라 글자는 16 이상, 터치 영역은 48 이상으로 하고 말줄임 없이 보여 줍니다.
결과
버튼 동작 테스트 66/66 · 위젯 테스트 45개 · 정적 분석 경고 0.

2. 카카오로 로그인해도 기관은 서버가 확인

설계
앱은 카카오 로그인 결과만 서버로 보내고, 서버가 카카오에 직접 확인한 전화번호로 담당자를 찾습니다. 담당자가 여러 기관에 속해 있으면 선택하게 하고, 이름으로는 찾지 않습니다. 기관 경계를 앱이 아니라 서버가 지키도록 한 설계입니다.

3. 릴리스 빌드에서만 생기는 문제

원인
디버그 빌드에서는 되던 로그인이 릴리스 빌드에서만 멈췄습니다. 코드 축소(R8)가 이름으로 호출되는 코드를 쓰지 않는 코드로 보고 지운 것이 원인이었습니다.
해결
로그(logcat)에서 지워진 클래스를 찾아 보존 규칙을 추가하고, 시제품 기간에는 축소를 끈 뒤 스토어 배포 때 규칙을 갖춰 다시 켜기로 했습니다. 오류는 화면에 한 줄로 보여 주고, 원문은 로그로 남깁니다.

배운 점

  • 체험 모드를 처음부터 넣어 두면, 실제 데이터 없이도 화면을 보여 주고 테스트할 수 있습니다.
  • 앱이 믿어도 되는 정보와 서버가 확인해야 하는 정보를 먼저 나눕니다.

회사 서비스라 코드는 비공개 저장소에 있습니다. 화면은 예시 데이터입니다.
