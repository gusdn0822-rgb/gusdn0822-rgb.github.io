온다정 — 노인 일자리 출퇴근·전화 서비스

노인 일자리 기관(시니어클럽)에서 어르신 수천 명의 출퇴근을 매일 기록하고, 그 기록을 활동일지와 급여까지 이어 주는 서비스입니다. 스마트폰이 어려운 어르신은 전화 한 통으로, 그 밖의 분은 링크로 출퇴근합니다.

  • 역할서비스개발자 — 백엔드·화면·전화 교환기·서버 운영
  • 상태여러 기관에서 운영 중
  • 기술FastAPI · PostgreSQL · Asterisk · Kamailio · Flutter
  • 기간2026 — 현재

구조

기관마다 전화번호와 교환기를 따로 두고, 모든 데이터는 기관 단위로 나뉩니다. 전화 출근은 교환기에서 출근 API까지 한 번에 이어집니다.

  1. 어르신 전화기관 출근 번호로 전화
  2. SIP 중계 (Kamailio)번호로 기관과 교환기 찾기
  3. 기관별 교환기 (Asterisk)안내 음성 · 연결 · 녹음
  4. FastAGI 상주 서버연결을 미리 열어 둠
  5. 백엔드 API (FastAPI)링크 출근과 담당자 웹·앱도 같은 API로
  6. PostgreSQL출퇴근 기록 · 급여

주요 작업

1. 출근 시간대 전화 몰림에 미리 대비

배경
출근 시각에는 전화가 한꺼번에 들어옵니다. 어르신은 전화를 받은 뒤 아무 소리가 없으면 끊긴 줄 알기 때문에, 전화가 몰릴 때 첫 안내가 얼마나 늦어지는지를 행사 전에 측정했습니다.
방법
외부 회선 없이 교환기 안에서 가상 통화를 만들고(가상 참여자 300명), 0.2초마다 채널 상태를 기록해 단계별 시간을 측정했습니다. 동시 90통일 때 첫 안내까지 최대 20.9초가 걸렸고, 지연은 통화마다 스크립트를 새로 실행하고 서버 연결을 새로 맺는 구간에서 생겼습니다.
개선
통화마다 실행하던 스크립트를 상주하는 FastAGI 서버로 바꾸고, 서버 연결 40개를 미리 열어 두는 풀과 오래된 연결을 교체하는 점검 작업을 넣었습니다. 상주 서버에 문제가 생기면 기존 방식으로 자동 전환되도록 했습니다.
결과
동시 90통에서 첫 안내까지 최대 20.9초 → 4.6초. 300통까지 끊긴 통화 0건. 자세한 글 보기 →

2. 여러 기관이 함께 쓰는 구조

설계
기관마다 전화번호·교환기·SIP 경로를 따로 두고, 모든 데이터는 기관 ID로 구분합니다. 권한 범위와 별개로 모든 조회에 기관 조건을 항상 거는 함수를 두었고, 기관을 확인할 수 없으면 조회하지 않습니다. 같은 이름의 기관이 실제로 여럿 있어서, 이름이 아니라 ID로만 구분합니다.
원칙
기능은 모든 기관에 공통으로 제공하고, 기관마다 다른 운영 방식은 코드가 아니라 명단 엑셀의 옵션 열로 설정합니다. 새 기관을 추가할 때 코드를 수정하지 않습니다.
결과
"INSERT·SELECT·UPDATE·DELETE에는 항상 기관 조건"을 팀 코드 규칙으로 문서화해, 새 코드도 같은 기준으로 점검합니다.

3. 기관마다 다른 명단 엑셀을 하나의 양식으로

배경
기관마다 쓰던 명단 엑셀 형식이 달라(기존 형식 5가지, 통합 양식 7개 시트) 담당자가 직접 맞추던 작업을 줄이고 싶었습니다.
개선
통합 양식 변환기를 만들고, 기관 파일을 가명 처리한 사본으로 회귀 테스트를 구성했습니다. 같은 파일을 두 번 올려도 결과가 같게 하고, 반영 직전·직후 데이터를 함께 백업해 해당 기관만 롤백할 수 있게 했습니다. 인식하지 못한 열이 있으면 화면에서 먼저 알려 줍니다.
결과
회귀 테스트 85건 통과 · 실패 0. 양식을 바꿀 때는 이 테스트부터 실행합니다.

4. 클라우드 이전

작업
서비스 서버를 오라클 클라우드로 옮기면서 전환과 롤백 절차를 스크립트로 만들고, 전환 전후 데이터 건수를 대조했습니다. 현장 담당자를 위한 담당자 앱도 만들었습니다.

배운 점

  • 어르신 서비스에서는 '처리됐다'보다 '들었다'가 중요합니다. 기록이 맞아도 긴 침묵은 실패라서, 행사 전에 몰림 상황을 측정합니다.
  • 여러 기관이 쓰는 서비스는 경계를 처음부터 코드 규칙으로 둡니다.
  • 엑셀처럼 사람이 만드는 입력은 회귀 테스트로 지킵니다.

회사 서비스라 코드는 비공개 저장소에 있습니다. 숫자는 테스트와 운영 중 직접 측정한 값이고, 고객 기관 정보는 넣지 않았습니다.
