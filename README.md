# 남현우 포트폴리오

https://gusdn0822-rgb.github.io

서비스개발자 남현우의 포트폴리오 사이트입니다. 순수 HTML·CSS(빌드 없음)로 GitHub Pages 에서 바로 열립니다.

- `index.html` — 소개 · 대표 수치 · 사례 · 프로젝트 · 기술 · 일하는 방식
- `cases/` — 사례 넷(온다정 · 온다정 직원 앱 · 에이전트원 · 사내 협업툴), 계기 → 한 일 → 결과
- `posts/` — 기술 글(동시 통화 부하 시험 · 한국어 찾기와 조합 Enter)
- `assets/img/` — 직원 앱 '둘러보기(가짜 시연 자료)' 화면
- `assets/style.css` — 색·글자·간격 토큰, 어두운 모드

회사 서비스의 코드와 고객 정보는 공개하지 않습니다. 사례의 수치는 운영·시험 중 직접 잰 값입니다.
