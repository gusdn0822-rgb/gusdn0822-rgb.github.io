# 남현우 포트폴리오

https://gusdn0822-rgb.github.io

풀스택 서비스개발자 남현우의 포트폴리오 사이트입니다. 빌드 없이 HTML·CSS·JavaScript만으로 GitHub Pages에서 바로 열립니다.

- `index.html` — 랜딩 페이지: 첫 화면 · 핵심 성과 · 서비스 스크롤 스토리 · 데모(초성·한영 오타 검색, AI 상담원 대화, 전화 흐름) · 프로젝트 · 경력 · 일하는 방식 · 글 · 연락
- `assets/landing.css`·`landing.js` — 랜딩 레이아웃과 인터랙션 (라이브러리 없음, 움직임 줄이기 설정 존중, JavaScript 없이도 내용은 모두 보임)
- `cases/` — 프로젝트 4개(온다정 · 에이전트원 · 온다정 담당자 앱 · 사내 협업툴), 핵심 성과 → 아키텍처 → 핵심 기여(문제·원인·해결·판단·결과) → 회고
- `posts/` — 기술 글(동시 통화 부하 테스트 · 한국어 검색과 한글 조합 Enter)
- `assets/img/` — 담당자 앱 체험 모드 화면(예시 데이터)
- `assets/style.css` — 색·글자·간격 토큰, 다크 모드

회사 프로젝트는 코드 대신 구조와 측정 결과로 소개합니다.
