초성·한영 오타 검색과 한글 조합 중 Enter 처리

사내 메신저를 만들며 한국어 사용자에 맞춘 세 가지 — 'ㄴㅎㅇ'으로 사람 찾기, 'skagusdn'을 '남현우'로 알아듣기, 한글을 조합하는 중에 누른 Enter 처리.

2026년 10월 · JavaScript · 데모 써 보기 →

1. 초성 검색 — 낱말 단위로

한글 음절은 유니코드에서 0xAC00부터 규칙적으로 배치되어 있어서, 초성은 나눗셈 한 번으로 꺼낼 수 있습니다(초성 하나당 중성 21 × 종성 28 = 588자).

const CHO = 'ㄱㄲㄴㄷㄸㄹㅁㅂㅃㅅㅆㅇㅈㅉㅊㅋㅌㅍㅎ';
const choseong = s => [...s].map(ch => {
  const c = ch.charCodeAt(0) - 0xAC00;
  return c >= 0 && c < 11172 ? CHO[Math.floor(c / 588)] : ch;
}).join('');

choseong('남현우');   // 'ㄴㅎㅇ'

처음에는 이름·직무·채널명을 한 줄로 이어 붙여 초성을 비교했는데, 낱말 경계를 넘어 엉뚱한 결과가 걸렸습니다(이모지 검색에서 'ㅂㅅ'이 두 낱말에 걸쳐 일치). 그래서 낱말마다 따로 초성을 비교합니다.

2. 영문 자판 오타를 한글로 — 두벌식 오토마타

한글 전환을 잊고 skagusdn을 입력하는 일은 흔합니다. 자판 위치를 자모로 바꾸는 것(s→ㄴ, k→ㅏ, a→ㅁ …)은 쉽지만, 핵심은 자모를 글자로 묶는 과정입니다.

  • 받침 뒤에 모음이 오면 그 받침은 다음 글자의 초성으로 넘어갑니다. ㄴㅏㅁㅎㅕㄴㅇㅜ → 남·현·우
  • 겹모음(ㅗ+ㅏ→ㅘ)과 겹받침(ㄹ+ㄱ→ㄺ)을 묶고, 겹받침 뒤에 모음이 오면 뒤쪽 자음만 넘깁니다.
  • Shift는 된소리(Q→ㅃ)와 O→ㅒ, P→ㅖ로 처리합니다.

검색은 하나의 함수로 모았습니다. 그대로 포함되는지 → 초성인지 → 영문이면 한글로 바꿔서 포함되는지 순서로 확인합니다. 사이드바·멘션·채널·할 일 검색 등 13곳이 같은 함수를 씁니다. 화면마다 따로 만들면 결과가 서로 달라지기 때문입니다.

3. 한글 조합 중에 누른 Enter

크롬과 엣지에서 '안녕'의 '녕'을 조합하는 도중 Enter를 누르면, keydown 이벤트가 isComposing = true로 먼저 옵니다. 이 이벤트를 무시하면 Enter를 두 번 눌러야 전송되고, 바로 전송하면 마지막 글자가 빠집니다. 사파리는 순서가 반대(조합이 먼저 끝나고 Enter)입니다.

function enterSends(input, send) {
  let pendingAt = 0;
  input.addEventListener('compositionend', () => {
    // 조합 중에 눌린 Enter는 조합이 끝난 직후 전송 — 1초 이내일 때만
    if (pendingAt && performance.now() - pendingAt < 1000) setTimeout(send, 0);
    pendingAt = 0;
  });
  return e => {                       // keydown에서 호출
    if (e.key !== 'Enter' || e.shiftKey) return false;
    if (e.isComposing) { pendingAt = performance.now(); return true; }
    e.preventDefault(); send(); return true;
  };
}

'1초 이내'라는 조건은, 예약해 둔 전송이 한참 뒤 다른 글자의 조합이 끝날 때 잘못 실행되지 않게 하려는 것입니다. 검증은 브라우저 자동화로 실제 한글 조합 입력을 재현해서 했습니다.

정리

  • 한국어 입력은 '글자'가 아니라 자모와 조합의 문제로 보면 풀립니다.
  • 검색 규칙은 한 함수로 — 화면마다 따로 만들면 사용자는 '여기서는 되고 저기서는 안 되는' 앱을 만나게 됩니다.
